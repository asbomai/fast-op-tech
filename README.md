# FAST Frontend Starter

Field Awareness and Situational Tracking (FAST) frontend starter built with React, TypeScript and Vite.

## Start

```bash
npm install
npm run dev
```

## Current scope

This starter contains the frontend shell, design tokens, navigation, reusable UI primitives, typed mock operational data, and placeholder pages.

## FAST design tokens

The implementation follows the supplied FAST Style Guide:
- Primary: #2563EB
- Background: #0B1220
- Surface: #121A2B
- Success: #22C55E
- Warning: #F59E0B
- Danger: #EF4444
- Info: #38BDF8
- 8px spacing grid
- 280px sidebar
- 80px header
- 12px card radius
- Inter / Roboto Mono typography

Map integration is intentionally left as a later phase.
